# SnagitCraft

<img src="Assets/logo-256.png" width="96" alt="SnagitCraft logo" />

(ชื่อเดิม "Snagit Anything" — เปลี่ยนเป็น SnagitCraft ในเวอร์ชัน 1.1.0)

โปรแกรมจับภาพหน้าจอสำหรับ Windows เขียนใหม่ทั้งหมดด้วย C# / .NET 8 (WPF) ใช้แทน Snagit 12 ที่ crash
เมื่อจับภาพรอบที่ 2 บนจอความละเอียดสูง (ไม่มีโค้ดของ Snagit อยู่ในโปรเจกต์นี้)

## สาเหตุที่ Snagit 12 crash และวิธีที่โปรแกรมนี้แก้

| Snagit 12 | SnagitCraft |
|---|---|
| `Snagit32.exe` เป็น 32-bit ไม่เปิด Large Address Aware ใช้หน่วยความจำได้ ≤ 2 GB | 64-bit (`PlatformTarget=x64`) |
| `OutOfMemoryException` ใน `DUCE.Channel.SyncFlush` ตอนวาดหน้าจอครอบภาพเต็มจอ | หน้าต่างครอบภาพทึบแสง (ไม่ใช้ `AllowsTransparency`) แยก 1 หน้าต่างต่อ 1 จอ แต่ละหน้าต่างใช้ภาพขนาดเท่าจอตัวเอง |
| หน่วยความจำสะสมข้ามรอบ | ทุกรอบสร้าง snapshot ใหม่แล้วคืนทั้งหมด; `Materialize` คัดลอกพิกเซลออกมาเพื่อไม่ให้ภาพย่อยค้างอ้างภาพเต็มจอ |
| ไม่รองรับ DPI ต่อจอ | Per-Monitor V2 DPI ใน `app.manifest` |
| error เดียวโปรแกรมหลุด | จับ exception ทุกจุด บันทึกลง `%APPDATA%\SnagitAnything\log.txt` แล้วทำงานต่อ |

ผลทดสอบ (`SnagitCraft.exe --stress 30`, 3 จอ รวม 7280×3240): ผ่าน 30/30 รอบ หน่วยความจำคงที่ ~560–705 MB

## ฟีเจอร์

- **จับภาพ**: ลากเลือกพื้นที่ / คลิกจับหน้าต่าง / `M` จอปัจจุบัน / `F` ทุกจอ — มีแว่นขยาย เส้นเล็ง และแสดงขนาดพิกเซล
- **โปรไฟล์การจับภาพ**: ภาพ (พื้นที่/หน้าต่าง), จอที่เมาส์อยู่, เต็มจอทุกจอ, ส่งไปคลิปบอร์ด, หน่วงเวลา 5 วินาที
- **หน้าต่างจับภาพลอย** (แบบ Snagit): ปุ่มแดงจับภาพตามโปรไฟล์ที่เลือก, แถบสีฟ้าเปิด/ปิดรายการโปรไฟล์,
  ปุ่มเปิดหน้าแก้ไข และปุ่มตั้งค่า — ซ่อนตัวเองตอนจับภาพ
  - **ชิดขอบจอ 4 ด้าน**: ลากแถบสีฟ้า/พื้นหลังไปใกล้ขอบ บน / ล่าง / ซ้าย / ขวา ของจอไหนก็ได้ จะติดขอบนั้นและจำไว้
    (บน/ล่าง = เรียงแนวนอน, ซ้าย/ขวา = แนวตั้ง; ขอบล่างอยู่เหนือ taskbar)
  - **ซ่อนอัตโนมัติ**: เหลือแค่แถบสีฟ้าบางๆ ที่ขอบจอ — เลื่อนเมาส์เข้าใกล้จะเลื่อนออกมา, เมาส์ออกไปจะซ่อนกลับ
    (ปิดได้ที่ ตั้งค่า › ซ่อนชิดขอบจออัตโนมัติ); ส่วนที่ซ่อนอยู่คลิกทะลุไปยังโปรแกรมข้างหลังได้
- **ปุ่มลัดตั้งเองได้** (⚙ ตั้งค่า): กด "ตั้งค่า…" แล้วกดปุ่มที่ต้องการ (รวม Print Screen และ Ctrl/Alt/Shift/Win)
  ค่าเริ่มต้น `Print Screen` / `Shift+Print Screen` / `Ctrl+Print Screen` / `Ctrl+Shift+Print Screen` (คลิปบอร์ด) —
  ใช้ low-level keyboard hook เพราะ Windows 11 ส่ง Print Screen ให้ Snipping Tool ก่อน `RegisterHotKey`
- **ที่เก็บภาพ**: ถ้าโฟลเดอร์ที่ตั้งไว้เขียนไม่ได้ (เช่น Windows Security › Controlled folder access บล็อก `รูปภาพ`)
  จะบันทึกที่ `%LOCALAPPDATA%\SnagitAnything\Captures` แทน และแจ้งวิธีอนุญาตครั้งเดียว — คัดลอก/เปิดหน้าแก้ไขยังทำงานเสมอ
- **หน่วงเวลา** 3/5/10 วินาที, คัดลอกไปคลิปบอร์ด, บันทึกอัตโนมัติ (PNG/JPG/BMP) ลง `รูปภาพ\SnagitCraft\วันที่\`
- **หน้าแก้ไข (แบบ Snagit Editor)** — ธีมมืด, หน้าต่างเดียวรับทุกภาพ:
  - แถบด่วน (บันทึก / เลิกทำ / ทำซ้ำ / คัดลอก) บนแถบชื่อ, เมนู **ไฟล์** (ใหม่จากคลิปบอร์ด, เปิด, บันทึก, บันทึกเป็น, พิมพ์)
  - แท็บ **เครื่องมือ**: เลือก, Callout, ลูกศร, ปากกา, ไฮไลต์, ข้อความ, เส้น, สี่เหลี่ยม, วงรี, ลำดับขั้น ①②③, เบลอ, ครอบตัด
    · **สไตล์ด่วน** (Quick Styles) ต่อเครื่องมือ · **เส้นขอบ / สีพื้น / เอฟเฟกต์ (เงา)** · ขนาดตัวอักษร
    · **เริ่มลำดับใหม่** · **คัดลอกทั้งหมด**
  - แท็บ **รูปภาพ**: ครอบตัด, ตัดขอบ (Trim), ปรับขนาด, หมุนซ้าย/ขวา, กลับด้าน, กรอบภาพ, เงาภาพ, ขาวดำ
  - แท็บ **แชร์** (คลิปบอร์ด, ไฟล์, พิมพ์, แสดงในโฟลเดอร์) และ **คลังภาพ**
  - **รูปแยกจากพื้นหลัง**: ภาพที่จับได้เป็นวัตถุหนึ่งชิ้นบนพื้นหลัง (canvas) —
    คลิกรูปแล้วลากมุมสีฟ้า = ย่อ/ขยายเฉพาะรูป, ลากตัวรูป = ย้ายบนพื้นหลัง;
    จุดจับสีขาว 8 จุดรอบนอก (ไม่ได้เลือกรูป / กด Esc) = ขยาย/ลดพื้นหลังเท่านั้น (ส่วนว่างโปร่งใส แสดงลายตาราง);
    Shift + ลากมุมพื้นหลัง = ย่อ/ขยายทั้งภาพรวม, หรือ รูปภาพ › ปรับขนาด (%)
  - **Ctrl+A** เลือกทั้งหมด • **Ctrl+C** คัดลอกภาพทั้งหมด (PNG + Bitmap — วางได้ใน Word, LINE, Paint, เบราว์เซอร์) •
    **Ctrl+V** วางรูปจากคลิปบอร์ดขนาดจริงเป็นวัตถุที่ย้ายและย่อ/ขยายได้ (ล็อกสัดส่วน, Shift = ไม่ล็อก);
    ถ้ารูปที่วางใหญ่กว่าพื้นหลัง พื้นหลังจะขยายตามให้อัตโนมัติ (Ctrl+Z ครั้งเดียวย้อนทั้งหมด) • วางข้อความได้ด้วย
  - ลำดับขั้น: ลากจุดจับเพื่อย่อ/ขยาย (คงสี่เหลี่ยมจัตุรัส), ดับเบิลคลิกเปลี่ยนเลขหรือใส่ตัวอักษร (เช่น A) —
    พิมพ์เลขจากคีย์บอร์ดภาษาไทยได้ (ๅ/-ภถุึคตจ และ ๐–๙ แปลงเป็น 1–0), ลำดับถัดไปนับต่อจากเลขที่แก้
  - วัตถุทุกชิ้นแก้ไขได้ภายหลัง: ย้าย, ลากจุดจับเพื่อปรับขนาด/ปลายลูกศร, เปลี่ยนสไตล์, ดับเบิลคลิกแก้ข้อความ,
    คลิกขวา = ทำสำเนา / นำมาหน้าสุด / ส่งไปหลังสุด / ลบ, ปุ่มลูกศรเลื่อนทีละ 1 px (Shift = 10 px)
  - **ถาดภาพ** ด้านล่างแสดงภาพล่าสุด คลิกเพื่อสลับภาพ, แถบสถานะแสดงขนาดภาพ ที่อยู่ไฟล์ และตัวเลื่อนซูม
- **ภาพล่าสุด** ในหน้าหลัก, ถาดระบบ (tray), เปิดได้ครั้งละหนึ่งโปรแกรม, เปิดไฟล์ภาพจาก command line เข้าหน้าแก้ไขโดยตรง

ปุ่มลัดในหน้าแก้ไข: V เลือก • K Callout • A ลูกศร • P ปากกา • H ไฮไลต์ • T ข้อความ • L เส้น • R สี่เหลี่ยม • E วงรี •
S ลำดับขั้น • B เบลอ • C ครอบตัด • Delete ลบ • Ctrl+D ทำสำเนา • Ctrl+Z/Y • Ctrl+C คัดลอกทั้งหมด • Ctrl+N ใหม่จากคลิปบอร์ด •
Ctrl+O เปิด • Ctrl+P พิมพ์ • Ctrl+S บันทึก • Ctrl+Shift+S บันทึกเป็น • Ctrl+0 พอดีจอ • Ctrl+1 100% • Shift ขณะลาก = 45° / สี่เหลี่ยมจัตุรัส

## โลโก้ / ไอคอน

โลโก้มาจากไฟล์ภาพไฟล์เดียว (`Assets\logo.png`) — เปลี่ยนเป็นภาพใหม่ได้ด้วยคำสั่งเดียว:

```bash
powershell -STA -File installer\set-logo.ps1 -Source C:\path\to\griffin.png
```

สคริปต์จะครอปเป็นสี่เหลี่ยมจัตุรัส ทำมุมมนแบบไอคอนชุด Craft (ใส่ `-NoRoundCorners` ถ้าภาพมีมุมมนอยู่แล้ว)
แล้วสร้าง `Assets\logo.png`, `Assets\logo-256.png` (หน้าติดตั้ง) และ `Assetspp.ico` (16–256 px: exe, ถาดระบบ, หน้าต่าง)
จากนั้น build ใหม่ / สร้างชุดติดตั้งใหม่

## ชุดติดตั้ง

```bash
powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1
```

ได้ไฟล์ `dist\SnagitCraft-Setup-1.1.0.exe` (~49 MB) — รวม .NET ไว้แล้ว เครื่องปลายทางไม่ต้องติดตั้งอะไรเพิ่ม (Windows 10 1809+ / 11, 64-bit)

- ติดตั้งแบบผู้ใช้คนเดียวโดยไม่ต้องใช้สิทธิ์ Admin (เลือก "ทุกผู้ใช้" ได้ในตัวติดตั้ง), ทางลัดใน Start menu,
  ตัวเลือก: ทางลัดบนเดสก์ท็อป, เปิดพร้อม Windows (ย่อไว้ที่ถาดระบบ)
- ปิดโปรแกรมที่เปิดอยู่ให้ก่อนอัปเดต, ถอนการติดตั้งได้จาก Settings › Apps (เก็บการตั้งค่าและภาพที่จับไว้)
- ต้องมี .NET 8 SDK และ Inno Setup 6 (`winget install JRSoftware.InnoSetup`); เปลี่ยนเวอร์ชันได้ด้วย `-Version 1.1.1`
- ไฟล์ติดตั้งยังไม่ได้เซ็นดิจิทัล — Windows SmartScreen จะเตือน "Windows protected your PC" ครั้งแรก (กด More info › Run anyway)

## Build / Run

```bash
dotnet build -c Release
```

ไฟล์โปรแกรมอยู่ที่ `bin\Release\net8.0-windows\win-x64\SnagitCraft.exe` (ต้องมี .NET 8 Desktop Runtime)

ทดสอบจับภาพต่อเนื่อง: `SnagitCraft.exe --stress 30` → รายงานที่ `%TEMP%\SnagitAnything-stress\report.txt`

## ยังไม่มี (เทียบกับ Snagit 12)

จับภาพแบบเลื่อนหน้า (scrolling capture), อัดวิดีโอหน้าจอ, OCR, แชร์ไปบริการออนไลน์
